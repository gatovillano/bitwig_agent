# Bitwig MCP Server & AI Agent (Python Package)

This package contains the Python implementation of the **Bitwig MCP Server**, the **LiteLLM-powered Agent CLI**, and the **Music Theory Engine** for Bitwig Studio 6.0+.

For full documentation, architecture diagrams, MCP tool reference, and installation guides, please see the [main README](../README.md).

### Quick Install
```bash
pip install -e .
```

### Running the MCP Server
```bash
bitwig-agent-mcp
```

### Running the Interactive Agent CLI
```bash
bitwig-agent
```
